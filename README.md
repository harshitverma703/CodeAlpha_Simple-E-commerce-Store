# CodeAlpha_Simple-E-commerce-Store
<h2>A responsive full-stack e-commerce website built as an internship project.</h2>

The application allows users to browse products, view product details, register/login, manage a shopping cart, place orders, and view their order history.

<h3>Customer Features</h3>-

Responsive homepage.
Product listing page.
Product search.
Product category filtering.
Product details page.
Product images.
Shopping cart.
Increase/decrease product quantity.
Remove products from cart.
Automatic cart total calculation.
User registration.
User login.
JWT-based authentication.
Checkout and shipping details.
Order processing.
Order history.
Responsive mobile navigation.

<h3>Database Features</h3>
The MySQL database stores:
Users
Products
Orders
Order items

<h3>Frontend:</h3>
HTML5
CSS3
JavaScript (ES Modules)
Responsive CSS Grid/Flexbox
Local Storage for cart and authentication token
